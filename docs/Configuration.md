# 工作区配置

在 Settings 首页直接进入工作流、Capture 模板或文件与议程。有效的选择立即保存；
文本在结束编辑时保存；新建状态序列、模板在局部编辑页确认。
本机持久化成功后配置才生效，随后通过现有工作区同步队列上传。

文件固定为工作区根目录的 `config.json`，使用 UTF-8 严格 JSON。
初次连接不创建文件；没有配置时采用通用 TODO/DONE 工作流、`inbox.org`
和自动发现的可见 `.org` 文件。经典工作流是显式选择的预设。
修改路径或关键字不会移动文件，也不会改写已有 Org 内容。

设置按工作区、Org 任务、此设备和配置工具分组，不再设置“工作区配置”中转页。
外观在首页直接选择；提醒开关、权限和时间统一在“提醒”页，并标明本机与共享设置。
工作区与同步页直接展示连接、保存状态和冲突入口，不再进入重复的同步详情页。
工作区只有一条默认状态序列。“进行中”和“终结”列表直接拖动排序，各自提供添加按钮；
新建、完成、重新打开状态在同一页选择。排序与添加自动保存，取消添加不会修改配置。
状态长按菜单可移组或删除，不能移除组内最后一个状态。
状态详情以编辑弹窗提供样式预览；历史记录规则就在工作流页下方。
“文件与议程”合并议程来源、Inbox、附件、日记、归档和 Refile 路径。
Capture 编辑按详情、目标、Org 源码和插入方式分组；不能删除最后一个模板，
删除默认模板时会将剩余的第一个模板设为默认。
JSON 预览、经典预设及恢复默认位于首页可直达的“配置文件”页；
JSON 原地展开，不增加一层导航。Emacs 提取同样由首页直接进入。

## 格式与优先级

最小配置：

```json
{"version": 1}
```

Schema 见 `config.schema.json`，实例见 `config.example.json`。
省略对象字段使用内置默认值，显式数组替换默认数组。
关键字／模板使用稳定 ID；关键字显示名称不影响源文 token。
所有普通路径相对工作区；归档文件路径相对源文件目录，支持 `%s`。
文件内 `#+TODO`、`#+SEQ_TODO`、`#+TYP_TODO` 覆盖工作区状态序列，
并解析快速选择键及 `!`、`@`、`/` 日志标记。
`workflow.sequences` 必须恰好包含一条默认序列；已有多序列配置会提示错误，
不会自动丢弃任何状态。Org 文件自身的多个本地序列声明仍按文件解析。

状态图标只能使用：
`default, circle, arrow, hourglass, pause, moon, exclamation, flag, star, check, cross`。
颜色只能使用：
`default, gray, red, orange, amber, green, cyan, blue, purple, pink`。
不支持任意 SF Symbols 或十六进制颜色；内置色板适配浅色／深色。

图标／颜色仅用于工作流状态。`default`（或省略字段）继承原有状态样式，
经典预设也保留原配色；只改名称、快捷键或日志规则不会改变样式。
全局强调色、标签、优先级、条目类型、导航外观均固定，不提供配置。
已明确写入的状态颜色仍保留；在状态设置中选 `default` 可恢复原样式。
新任务不会自动添加优先级标记。

主要分组：

| 分组 | 内容 |
|---|---|
| `workflow` | 一条默认 Process/Terminal 序列、默认状态、关键字名称／样式／选择键／进出日志 |
| `capture` | 默认模板、模板列表、目标、Org 正文、模板选择键 |
| `agenda` | 包含／排除文件与目录 |
| `files` | Inbox、附件、日记目录、归档、Refile |
| `logging` | 完成、重新计划、修改 deadline 的日志，以及 drawer 名称 |
| `reminders` | 提前分钟、重复分钟、deadline 预警天数 |

`logging` 规则为 `none/time/note`，`drawer` 为空时写入正文。
关键字同时触发进入和离开规则只写一条状态日志，备注要求优先。
需要备注的快捷操作不会绕过备注要求；使用条目编辑器填写后保存。
工作区配置不控制设备登录凭据、通知权限、通知启用开关和系统外观模式。

空议程源列表自动发现文件；
隐藏目录、`archives`、`Unsaved Edits` 和 `.org_archive` 不进入默认议程。
Dashboard 固定显示逾期、未来七天、近期截止和按工作流状态分组的未安排任务；
没有自定义视图、筛选表达式或布局编辑器。日记固定按年分文件。
应用快捷键保持内置行为，例如 `⌘N` 新建；状态和模板自身的选择键仍可配置。

## Capture

类型：`entry/item/checkitem/plain`。
目标：`file/headline/outline/datetree`；`outline` 为逐级标题名称数组。
日期树使用年、月、日三级标题，可位于指定标题路径之下。
缺失标题必须确认创建；重复匹配会报错，不随意选取。
`entry` 模板以 `* ` 开头，插入时按目标层级调整真实标题，不修改代码块中的星号。

支持：

- `%%`：字面百分号；`%?`：用户提供的光标位置文本。
- `%t/%T/%u/%U`：活动／非活动、日期／带时间时间戳。
- `%^{问题|默认值|候选值}`，以及 `%^{问题}t/T/u/U` 日期输入。
- `%<…>` 的 `%Y %m %d %H %M %a %A %b %B %%` 日期格式。
- `%a/%i/%x`：用户显式填写的链接、选中文本、粘贴内容。
- `prepend`、`emptyLines`：插入位置和空行。

状态、标签、优先级、属性、日期和重复规则直接写在模板的 Org 正文中，
不再维护第二套结构化 defaults 或字段覆盖优先级。

模板试填显示生成的 Org，不写入工作区。实际 Capture 必须先预览，
再确认；目标文件或配置在此期间变化会要求重新预览。
不执行 Lisp、函数目标、外部模板包含或脚本。未支持占位符会阻止保存，
不是“原样保留但假装支持”。
目前快速模板键直接支持单字符；分组及多字符键保存在配置中，
多字符选择通过模板菜单完成，不模拟 Emacs 多键输入状态机。

## 保存、安全与兼容

非法配置保留原文件，并继续使用该工作区最后有效配置；
没有缓存时使用通用默认。设置页显示错误并禁止覆盖损坏文件。
修复外部文件并同步，或删除该文件，可恢复正常编辑。
未知版本禁止写回。未知字段提示“不生效”并保留；对象数组按 `id`
匹配原成员，避免 GUI 编辑丢失扩展字段。旧版本的 `appearance`、`shortcuts`、
`tags`、`priorities`、自定义视图和模板 `defaults` 不再应用；
其中必要的模板默认值应写进 Org 正文。不会主动改写用户工作区中的旧文件。

编辑草稿与配置修订绑定，外部变更不会自动重置草稿。
多设备冲突通过“工作区与同步”处理，不自动合并配置。
“保留两份”的配置恢复副本存入 `orgenda/Unsaved Edits/*.md`，
内容仍是原 JSON，但不会作为第二份配置生效。
正常删除配置恢复通用默认；未同步编辑仍适用现有冲突规则。

## 从 Emacs 提取

Settings 中的 **Extract from Emacs** 提供“生成”和“更新”两种可复制 prompt，
包括实际支持格式、内置图标／色板、当前配置以及不执行代码的限制。
把 prompt 与 Emacs 配置交给你选择的 AI 工具，将生成的 **JSON 部分**
写到工作区 `config.json`，再同步。转换报告应单独保存。

Orgenda 不上传 Emacs 配置、不调用 AI，也不提供粘贴 JSON／导入文件入口。
动态 Lisp、agenda skip 函数和无法确定的路径应在转换报告中说明。
